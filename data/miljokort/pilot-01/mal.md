# Miljøkortmal – versjon 0.1

Anleggsnavn / operatør / kommune / kontrolltidspunkt / ansvarlig funksjon.
Kartkobling: verifisert havne-ID eller uavklart kobling. Skill sjøpolygon, landareal og delt tjeneste.

For hvert tema: spylevann, slipestøv, farlig avfall, septik, beredskap, naturverdier, organisering og effekt:

| Felt | Innhold |
| --- | --- |
| Relevans | Relevant / ikke relevant med begrunnelse / uavklart. |
| Påstand | Konkret tiltak og fysisk omfang. |
| Tiltaksstatus | Planlagt / under etablering / opplyst etablert / drift dokumentert / ukjent. |
| Bevis | Operatør, leverandør, myndighetsdokument, befaring eller målerapport. |
| Kilde | URL, utgiver, dokumentdato med presisjon, avsnitt og kontrolltidspunkt. |
| Lokal kopi | Fil og SHA-256; endret nettside må gi ny kildeversjon. |
| Hulltype | Dokumentasjonshull / bekreftet tiltakshull / ikke relevant / kildeavvik. |
| Oppfølging | Manglende bevis, konkret spørsmål, ansvarlig funksjon og avtalt dato hvis kjent. |
| Effekt | Skill driftsresultat, redusert utslipp og økologisk endring. Oppgi metode og måleperiode. |

Ukjent er ikke nei. Regel eller plan er ikke dokumentert gjennomføring. Produktets rensegrad er ikke anleggets måleresultat. Flere gjengivelser av samme pressemelding er ikke uavhengige bekreftelser. Sammenlign bare havner med relevant aktivitet. Bruk ikke en samlet miljøscore før datagrunnlag og metode er avklart.

Denne piloten dekker utvalgte temaer, ikke en full miljøkartlegging. Ikke undersøkte temaer må beholdes uavklart. Ingen juridisk etterlevelsesvurdering inngår.
