# Bispebrygga – suppleringsforslag 2026-11-01

Ett nytt sjøpolygon, foreslått ID 0301-H33-B01 / havnegruppe 0301-H33. Godkjent av brukeren og innlemmet 2026-11-01. Opprinnelig Oslo rev-01 er uendret. Samlefil og nettsted er oppdatert; miljøkort MK-06 er koblet til 0301-H33.

## Stedfesting og avgrensning

VELiHAVN oppgir havnen ved 59.879167, 10.765, Grønsundveien 16, og lenker til samme operatør som miljøkort MK-06. Esri-bildet viser et sammenhengende bryggeanlegg øst for Ormsundveien ved dette punktet, med landopplag rett øst. Dette gir sterkere stedfesting enn registeradressen alene. Operatøren oppgir 72 sjøplasser. Antallet gjelder foreningen og er ikke kontrolltelt innenfor dette omrisset.

Omrisset dekker det sentrale sammenhengende bryggeanlegget og mellomliggende sjø, ca. 3 396 m². Landopplag og sørlige enkeltbrygger er utelatt; det er uavklart om disse også drives av foreningen. Drifts-/eiendomsgrenser og nøyaktig spyleplass er ikke dokumentert. Bildets lokale opptaksdato er ukjent. Avgrensningen trenger datert ortofotokontroll.

Nærmeste eksisterende polygon er 0301-H29-B01 Padda småbåthavn, lenger sør. Forslaget overlapper ingen godkjente polygoner. Ingen eksisterende ID 0301-H33 finnes i godkjent Oslo-leveranse.
